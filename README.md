# Web Monitor

## Intro

To monitore certain web applications

## Setup

To setup the project locally you first have to install two golang tools with the following commands:

```shell
go install github.com/jackc/tern/v2@latest
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
```

OBS: You only need the sqlc tool if you're creating new queries for the application
